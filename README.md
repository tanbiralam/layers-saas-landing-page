# Layers - Landing Page

A modern, responsive landing page for Layers built with **Next.js 16**, **React 19**, **TypeScript**, and **Tailwind CSS**. Features smooth animations with Framer Motion and interactive components.

## 🚀 Quick Start

### Install Dependencies

```bash
npm install
```

### Run Development Server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## 📦 Available Scripts

```bash
npm run dev      # Start development server
npm run build    # Create production build
npm start        # Start production server
npm run lint     # Run ESLint checks
```

## 🛠️ Tech Stack

- **Next.js 16.1** - React framework
- **React 19.2** - UI library
- **TypeScript** - Type safety
- **Tailwind CSS 4** - Styling
- **Framer Motion** - Animations
- **CVA** - Component variants

## 📁 Project Structure

```
components/       # Reusable UI components (Button, Avatar, etc.)
sections/         # Page sections (Hero, Features, Navbar, etc.)
assets/           # Images and static files
app/              # Next.js app router
```

## ✨ Features

- Animated hero section with interactive elements
- Responsive navigation bar
- Feature showcase section
- Integration display (Figma, Slack, Notion, GitHub, etc.)
- FAQ section
- Call-to-action sections
- Fully responsive design
- Smooth scroll animations

## 🚀 Deploy

Deploy to Vercel with one command:

```bash
npm run build
vercel deploy
```

Or use Netlify, AWS Amplify, or any Node.js hosting.
